# Facebook Content Studio — Web App

واجهة ويب عربية لتحويل سكربت إنشاء منشورات فيسبوك إلى لوحة تحكم مستضافة.

## الميزات الحالية
- لوحة تحكم متجاوبة بالعربية.
- إعدادات الصفحة واللهجة والعلامة المائية وخطة المحتوى.
- تخزين مفاتيح AI وMeta على الخادم في `.env` (لا ترفعها إلى Git).
- ربط Facebook عبر User Token، تبادل التوكن ومحاولة جلب الصفحات واختيار الصفحة.
- توليد مسودات نصية وصور عربية باستخدام محرك المشروع الأصلي.
- مراجعة المسودة ثم النشر اليدوي.
- إرسال خطة منشورات إلى جدولة فيسبوك مع أوقات الخطة.
- سجل محلي للمسودات والحالات.

## نشره كموقع
ارفع المشروع إلى GitHub ثم أنشئ Web Service على Render أو خدمة Python Web Service مشابهة:
- Build command: `pip install -r requirements.txt`
- Start command: `gunicorn app:app --bind 0.0.0.0:$PORT --workers 1 --timeout 900`
- أضف متغير البيئة `DASHBOARD_PASSWORD` بكلمة مرور قوية، و`FLASK_SECRET_KEY` بقيمة عشوائية طويلة.
- أضف قرصاً دائماً (persistent disk) واربطه بمجلد المشروع/بياناته إن كانت المنصة تدعم ذلك، أو انقل التخزين إلى قاعدة بيانات قبل الاستخدام الإنتاجي.
- أضف `GEMINI_API_KEY` وبيانات Meta من صفحة الإعدادات. استخدم HTTPS.

## مهم قبل الإنتاج
هذه نسخة أولية قابلة للتشغيل وليست خدمة SaaS متعددة المستخدمين. تخزين `.env` و`posted.json` و`config.json` على القرص المحلي ليس مناسباً لتعدد المستخدمين أو بيئات ephemeral. قبل فتحها للجمهور يلزم قاعدة بيانات دائمة، فصل بيانات كل حساب، CSRF/rate limiting، صلاحيات أدق، إدارة المهام الطويلة في queue، وتدقيق شامل لصلاحيات Meta. لا تضع App Secret أو Page Token في مستودع عام.
- ريلز يعتمد على FFmpeg الموجود في بيئة الاستضافة؛ إن لم يكن موجوداً فلن يعمل توليد الفيديو.
- مراقبة التفاعل والإخفاء/الإظهار التلقائي ليست موصولة بلوحة الويب في هذه النسخة.
- التوليد قد يفشل بسبب حصص مزوّد الذكاء الاصطناعي أو تغيّر النماذج. استخدم اسم نموذج متاحاً في حسابك.
- لم يتم إجراء نشر حقيقي على صفحة فيسبوك لأن بيانات المستخدم غير متوفرة في بيئة الاختبار.
- ابدأ بتجربة مسودة، راجع كل محتوى ديني، ثم اختبر النشر ببوست واحد.
